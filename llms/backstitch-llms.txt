# backstitch

> backstitch is a Techstars-backed Kansas City company offering an employee and total-rewards communications platform plus a developer content-curation API. The API builds and manages "topics" that aggregate and filter content from social, RSS, video, deals, subreddit, and custom sources, and returns normalized result objects (articles, statuses, photos, videos, products, services, hotels) or embeds them via a JavaScript widget. It is offered as legacy v1 and recommended v2 over REST/JSON, authenticated with an Organization Key plus per-topic tokens.

## APIs
- [backstitch Content Curation API (docs)](https://docs.backstit.ch/api/): REST/JSON topic + results API. Base URL https://api.backstit.ch/v2 (legacy v1 at https://api.backstit.ch/v1/topic).
