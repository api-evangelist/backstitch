# backstitch

> backstitch is a Techstars-backed Kansas City company offering an employee and total-rewards communications platform plus a developer content-curation API. The API builds and manages "topics" that aggregate and filter content from social, RSS, video, deals, subreddit, and custom sources, and returns normalized result objects (articles, statuses, photos, videos, products, services, hotels) or embeds them via a JavaScript widget. It is offered as legacy v1 and recommended v2 over REST/JSON, authenticated with an Organization Key plus per-topic tokens.

## APIs
- [backstitch Content Curation API (docs)](https://docs.backstit.ch/api/): REST/JSON topic + results API. Base URL https://api.backstit.ch/v2 (legacy v1 at https://api.backstit.ch/v1/topic).

## What backstitch does not publish
Recorded so an agent does not go looking. Each was probed on 2026-08-13.
- No OpenAPI, Swagger, GraphQL SDL or AsyncAPI document at any location on api.backstit.ch, docs.backstit.ch or backstitch.io.
- No first-party SDK on npm, PyPI, RubyGems, Maven Central, NuGet, Packagist, crates.io or pkg.go.dev. The `backstitch` package on PyPI belongs to a different author.
- No hosted MCP server and no A2A agent card.
- No `/.well-known/` document of any kind, on any host.
- No pricing page or published plan tiers — commercial entry is a "Request a Quote" form.
- No documented rate limits, rate-limit response headers, or 429 semantics.
- No webhooks, event surface, changelog, CLI, sandbox or test credentials.
- No idempotency key on any write operation.
